Working With You

Practical Excel help, without the black box

Every organisation's spreadsheets look a bit different, so the work usually starts with a conversation about what you're trying to achieve, not a fixed package. Below are the main ways I can help.

Automation Build

Turning a manual, repetitive process into something that runs with a click - usually built around Power Query, with VBA used where it adds genuine value rather than as the default. The result is a tool you can see inside and adjust yourself, not a black box.

Excel-Based Data Cleansing

Messy exports, inconsistent formatting, duplicate records, mismatched columns - cleaned up and structured so the data is actually usable, whether that's for reporting, analysis, or feeding into another system.

Data Migration Support

Small-scale support for moving data into a new CRM or system, using Excel to reshape, validate, and prepare your existing records so the migration goes smoothly and nothing important gets lost along the way.

Ongoing Support

Ad hoc maintenance and updates for tools I've previously built for you, so things keep running smoothly as your needs shift, without needing to start from scratch each time.

Remedial Excel

Got an old spreadsheet held together with legacy macros or fragile formulas? I can rebuild it using modern Excel features - Power Query, structured tables, and current formulas - so it's easier to maintain and less reliant on one person understanding how it works.

Available on request

Managed Reporting

For organisations that would rather hand off a recurring report entirely, I can take on the regular production of monthly or quarterly reports using tools built specifically for your data.

Not sure which of these fits what you need? Get in touch and we can work it out together.
